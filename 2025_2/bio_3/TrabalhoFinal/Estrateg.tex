\section{Estratégias de Simulação}

A estratégia adotada para a simulação foi o desenvolvimento de um biblioteca em Python denominada "Galapagos-Evo" que traduz a dinâmica evolutiva para o ambiente computacional utilizando a Orientação a Objetos para criar ``atores digitais'' que mimetizam entidades biológicas, desse modo, o nosso programa produz simulações de maneira análoga ao processo biológico, sendo possível simular não apenas as hipótese de Lynch, como os modelos mais simples vistos em aula.

A simulação utiliza um modelo de gerações sucessivas com cruzamentos, onde o genótipo possui tamanho variável e está sujeito a mutação e duplicação de genes. O teste principal consiste em comparar a evolução da complexidade genômica em populações de diferentes tamanhos. O código não possui um viés quanto ao destino evolutivo da simulação; ele apenas detém as definições fundamentais: o computador ``sabe'' o que constitui um Indivíduo, reconhece a existência de Sexo e delimita o ciclo de uma Geração.

A simulação opera de maneira estocástica  análoga à aleatoriedade da natureza. A cada iteração do código (uma geração), o algoritmo realiza a amostragem de indivíduos para cruzamento. Durante essa reprodução virtual, aplicam-se as taxas fixas de erro para gerar eventos de mutação e duplicação gênica sobre genótipos de tamanho variável. Ao controlar estritamente esses parâmetros e variar apenas o tamanho da população, o sistema permite testar \textit{in silico} as premissas de Lynch: verificar se a deriva genética em populações pequenas é suficiente para permitir o acúmulo de complexidade genômica passiva, independentemente de seleção.

Nosso código pode ser acessado por qualquer dispositivo com Python instalado através do seguinte comando no terminal: "pip install galapagos-evo", ou pelo link: https://github.com/TheFire888/galapagos.

\subsubsection*{Parâmetros Controlados} %ESSA È CRITÈRIO
Nossa simulação foi feita em três cenários principais em que um parâmetro foi variado enquanto os outros permaneceram fixos. O \textit{Cenário 1} variou o tamanho populacional, equanto o \textit{Cenário 2} variou a chance de mutação e o \textit{Cenário 3} o custo por gene extra no genótipo.
